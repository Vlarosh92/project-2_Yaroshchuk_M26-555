## Простая Консольная БД
Программа для создания простых баз данных, включает в себя возможность 
создавать и удалять таблицы, с записью по заданным параметрам данных.
Допускает ввод строковых, целочисленных и булевых значений.

## Работа с таблицами
Для процесса работы с таблицами используются следующие команды

<create_table> - создание таблицы.
Схема: create_table <имя_таблицы> <столбец_1:тип_данных_1> <столбец_2:тип_данных_2> .. 
Данная команда создает новую таблицу и добавляет её метаданные, в "db_meta.json",
и создает её файл в директории "data".
В название допустимы только латинские символы, цифры и нижнее подчеркивание.
Типы пишутся только в нижнем регистре, название атрибутов - регистрозависимые. 
Допустимые типы данных:
 - int;
 - str;
 - bool. 
Ошибки и исключения:
 - Таблица существует; 
 - Формат ввода не соответствует схеме;
 - Тип данных не соответствует допустимым.
Пример использования:
create_table table_name name:str salary:int active:bool


<drop_table> - удаляет существующую таблицу
Схема: drop_table <имя_таблицы>
Данная команда удаляет саму таблицу и обновляет список таблиц, 
а также удаляет её из директории "data"
Ошибки и исключения:
 - Таблицы не существует; 
 - Формат ввода не соответствует схеме.
Пример использования:
drop_table table_name 


<list_tables> - показывает список таблиц
Схема: list_tables 
Ошибки и исключения:
 - Формат ввода не соответствует схеме.
Пример использования:
list_tables

## Операции с данными

Для манипуляций с данными внутри таблицы используются следующие команды.

<insert> - создание новой записи в таблице.
Схема: insert into <имя_таблицы> values (<значение1>, <значение2>, ...)

Данная команда добавляет запись с атрибутами указанными в скобках, в таблицу указанной 
между "into" и "values". Запись производиться в файл формата json в директории "data". 
Допустимым является указание только одной таблицы и одного набора аргументов. 
Допустимые типы данных:
Типы данных в скобках должны соответствовать порядку типов данных указанных в метаданных таблицы.
Данные типа "str" - указываются только в кавычках, остальные типы данных без.
Вводимые данные типа "str" - являются регистрозависимыми, "bool" - регистронезависимыми.
Разделение вводимых атрибутов в скобках производиться через запятую.  
Ошибки и исключения:
 - Таблицы не существует; 
 - Формат ввода не соответствует указанной схеме;
 - Неверный тип данных (TypeError);
 - Несоответствие количества вводимых атрибутам количеству атрибутов таблицы.
Пример использования:
insert into table_name values ("name", 99999, True)


<select> - вывод данных из таблицы в консоль.
Схема: select from <имя_таблицы> where <столбец> = <значение>

Команда выполняет вывод в консоль данных из таблицы с фильтрацией по заданному условию. 
Вывод производиться в табличном виде. Название таблицы вводиться между 
"from" и "where". Условия вводятся после "where". Допустимо указывать только одно условие.
Также допустимо не указывать никаких условий, тогда таблица выведет все данные, пример схемы:
Схема: select from <имя_таблицы>

Допустимые типы данных:
Соответствуют типу данных атрибута по которому производиться фильтрация. Данные типа "str" 
необходимо брать в кавычки, другие допустимые типы данных должны вводиться без кавычек.
Тип "str" также является регистрозависимым, а "bool" - регистронезависимым.
Ошибки и исключения:
 - Таблицы не существует; 
 - Формат ввода не соответствует указанной схеме;
 - Неверный тип данных (TypeError);
 - Атрибута по которому производиться фильтрация не существует;
 - Запрос к несуществующему элементу.
Пример использования:
select from table_name where name = "name"


<update> - обновления существующей записи.
Схема: update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия>

Команда обновляет запись в таблице указанной между "update" и "set", меняя значение
указанное между "set" и "where", по условию указанному после "where". Меняются все значения, 
соответствующие заданному условию, в атрибуте указанному после "set". Допустимо указывать только 
один изменяемый атрибут и только одно условие выборки. Название атрибутов указываются без кавычек, 
значения смотри ниже.
Допустимые типы данных:
Типы данных изменяемого атрибута и типы данных условия, должны совпадать с типами данных 
соответствующих столбцов в метаданных таблицы. Данные типа "str" 
необходимо брать в кавычки, другие допустимые типы данных должны вводиться без кавычек.
Тип "str" - регистрозависимый, "bool" - регистронезависимый.
Ошибки и исключения:
 - Таблицы не существует; 
 - Формат ввода не соответствует указанной схеме;
 - Неверный тип данных (TypeError);
 - Атрибута по которому производиться фильтрация не существует;
 - Атрибут по которому производиться замена значений не существует;
 - Запрос к несуществующему элементу.
Пример использования:
update table_name set name = "New_Name" where salary = 99999

<delete> - удаление записи по условию. 
Схема: delete from <имя_таблицы> where <столбец> = <значение>

Команда выполняет удаление из таблицы данных с фильтрацией по заданному условию. 
Название таблицы вводиться между "from" и "where". 
Условия вводятся после "where". Допустимо указывать только одно условие.
Допустимые типы данных:
Соответствуют типу данных атрибута по которому производиться фильтрация. Данные типа "str" 
необходимо брать в кавычки, другие допустимые типы данных должны вводиться без кавычек.
"str" - регистрозависимый, "bool" - регистронезависимый.
Ошибки и исключения:
 - Таблицы не существует; 
 - Формат ввода не соответствует указанной схеме;
 - Неверный тип данных (TypeError);
 - Атрибута по которому производиться фильтрация не существует;
 - Запрос к несуществующему элементу.
Пример использования:
delete from table_name where name = "New_Name"


<info> - вывод данных о таблице. 
Схема: info <имя_таблицы>

Выводит название таблицы, её метаданные, а также количество записей.
Ошибки и исключения:
 - Таблицы не существует; 
 - Формат ввода не соответствует указанной схеме.
Пример использования:
info table_name
