## Простая Консольная БД
Программа для создания простых баз данных, включает в себя возможность 
создавать и удалять таблицы, с записью по заданным параметрам данных.
Допускает ввод строковых, целочисленных и булевых значений.

## Работа с таблицами
Для процесса работы с таблицами используются следующие команды

<create_table> - создание таблицы.
Схема: create_table <имя_таблицы> <столбец_1:тип_данных_1> <столбец_2:тип_данных_2> .. 
Данная команда создает новую таблицу и добавляет её метаданные, в "db_meta.json".
В название допустимы только латинские символы, цифры и нижнее подчеркивание.
Типы пишутся только в нижнем регистре, название атрибутов - регистрозависимые. 
Допустимые типы данных:
 - int;
 - str;
 - bool. 
Ошибки и исключения:
 - Таблица существует; 
 - Формат ввода не соответствует схеме;
 - Тип данных не соответствует допустимым.
Пример использования:
create_table table_name name:str salary:int active:bool


<drop_table> - удаляет существующую таблицу
Схема: drop_table <имя_таблицы>
Данная команда удаляет саму таблицу и обновляет список таблиц.
Ошибки и исключения:
 - Таблицы не существует; 
 - Формат ввода не соответствует схеме.
Пример использования:
drop_table table_name 


<list_tables> - показывает список таблиц
Схема: list_tables 
Ошибки и исключения:
 - Формат ввода не соответствует схеме.
Пример использования:
list_tables
